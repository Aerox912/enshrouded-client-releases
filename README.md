# Enshrouded Mod Manager 4.4.11

[Download Regular](https://github.com/Aerox912/enshrouded-client-releases/releases/download/v4.4.11/Enshrouded-Mod-Manager-Regular-4.4.11.zip) or [download Admin](https://github.com/Aerox912/enshrouded-client-releases/releases/download/v4.4.11/Enshrouded-Mod-Manager-Admin-4.4.11.zip). Each ZIP includes Setup and a portable manager. Both editions offer Normal and Cheeze profiles and preserve saved choices.

Magic Storage is a **public-test feature**, enabled in fresh profiles in both editions. F4 opens searchable magic storage for the current altar area. Transfers need the matching server companion and ordinary storage permissions, without Creative approval.

After the manager upgrades, it automatically updates selected installed mods while the game is closed and the manager is idle. Settings and selections are preserved. Pending checkbox edits wait for Apply changes; failed updates stop and retain manual recovery.

Admin includes optional Creative Mode with integrated server-approved flight. Standalone Always Flying is removed and retired on upgrade. Creative remains Admin-only; installing Admin grants no privileges. Creative has stock-style tiles and blur, stable Journey browsing and corrected controller tab highlights. Vein Mining retains saved radius and supports mining immediately after a full client restart.

The local Storage test passed controller withdrawal/deposit, a same-item round trip, a five-item deposit and count conservation after reconnect. Missing Y glyphs and a stale cancelled footer after reopening remain UI issues. Matching batches, capacity/concurrency cases, server-restart persistence, live pressure recovery, sustained performance and multiplayer isolation remain unverified live. Do not repeat a transfer with an unknown outcome.

Hotkeys are under Settings > Hotkeys. Client managers do not contain server companions, private access lists or saves. Public dependencies download from pinned releases, and installation/update rollback is retained.
