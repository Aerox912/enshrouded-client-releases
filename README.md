# Enshrouded Mod Manager 4.4.14

[Download Regular](https://github.com/Aerox912/enshrouded-client-releases/releases/download/v4.4.14/Enshrouded-Mod-Manager-Regular-4.4.14.zip) or [download Admin](https://github.com/Aerox912/enshrouded-client-releases/releases/download/v4.4.14/Enshrouded-Mod-Manager-Admin-4.4.14.zip). Each ZIP includes Setup and a portable manager. Both editions offer Normal and Cheeze profiles and preserve saved choices.

Magic Storage is a **public-test feature**, required in all managed profiles in both editions, including profiles that previously disabled it. F4 remains the default. Settings > Hotkeys accepts supported single keys, including German Ü; click the Magic Storage key field and press the desired key. In-game conflict checks still protect existing bindings. Magic Storage opens searchable magic storage for the current altar area. Transfers need the matching server companion and ordinary storage permissions, without Creative approval.

Automatic updates are required while the manager runs. Manager checks run at startup and every 30 minutes; published mod changes are checked every minute and applied as soon as detected. Available local updates apply immediately. All checks and updates wait while the game runs and resume after exit. Other selections, hotkeys and settings are preserved, and optional checkbox edits remain unapplied. Failed updates stop and retain manual recovery. Finish required mod updates before launching through the manager; Uninstall all remains available. Fresh folders still need an initial Install action.

Admin includes optional Creative Mode with integrated server-approved flight. Standalone Always Flying is removed and retired on upgrade. Creative remains Admin-only; installing Admin grants no privileges. Creative has stock-style tiles and blur, stable Journey browsing and corrected controller tab highlights. Vein Mining retains saved radius and supports mining immediately after a full client restart.

The published preview.22 baseline passed controller withdrawal/deposit, a same-item round trip, a five-item deposit and count conservation after reconnect. Missing Y glyphs and a stale cancelled footer after reopening remain UI issues. Matching batches, capacity/concurrency cases, server-restart persistence, live pressure recovery, sustained performance and multiplayer isolation remain unverified live. Do not repeat a transfer with an unknown outcome.

Hotkeys are under Settings > Hotkeys. Client managers do not contain server companions, private access lists or saves. Public dependencies download from pinned releases, and installation/update rollback is retained.

Preview.23 changes keyboard handling only. German and US layouts passed offline native mapping checks; physical German-key gameplay and live transfers with this new client have not been re-tested. The server companion and other native mods are unchanged.
