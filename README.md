# Enshrouded Mod Manager

**Regular** and **Admin** editions, each with **Normal** and **Cheeze** profiles. Hover over a mod to learn what it does, or use its Nexus badge to visit the original author's page. Key bindings are centralized under **Settings > Hotkeys**.

[Download Regular 4.4.10](https://github.com/Aerox912/enshrouded-client-releases/releases/download/v4.4.10/Enshrouded-Mod-Manager-Regular-4.4.10.zip) or [download Admin 4.4.10](https://github.com/Aerox912/enshrouded-client-releases/releases/download/v4.4.10/Enshrouded-Mod-Manager-Admin-4.4.10.zip). Each ZIP contains a per-user Setup executable and **Enshrouded-Mods.exe** for portable use, stays below 15 MB and requires no GitHub login. Both profiles' Nexus originals and maintained patches are bundled; larger public dependencies download automatically without signing in.

The Admin edition includes optional **Creative Mode**, with the tested F7 input capture and Journey fixes. Its integrated F6 flight uses the matching Creative server companion and private server permissions. Admin grants no privileges. **Standalone Flight is unavailable** in this release; existing selections are removed when applying mod changes, with configuration and rollback retained. Creative is not selected automatically.

Both editions include the Vein Mining radius fixes. Installation and updates set Toggle, preserving your key and radius. F8 is the new-install activation key; F12 selects 5, 10 or 15 metres. Other modes remain configurable. Magic Storage is excluded pending its separate item-selection repair. Local F7 input, Journey mode and radius switching were user-confirmed; extended server performance, mining payout and complete native visual parity remain open checks.

Select Normal or Cheeze in the app to apply that profile's defaults with the game closed. You can also choose individual mods and apply a custom selection. Switching profiles keeps the same application and preserves hotkeys, minimap options, camera preferences, OptiScaler settings and the original uninstall baseline.

Normal includes the minimap, first-person camera, Electric Blink, Hoarder's Helper, OptiScaler, Workshop Speed 20x and the selected EMBER features. Cheeze adds Vein Mining, Auto Loot, Max Stack, Unlimited Gifting Range, Rested Enhanced and Grappling Hook Pull 2x. Both profiles enable EMBER magic furniture, magic production stations, buff refresh, no-build-zone removal and building in Shroud fog, with Flame Altar requirements preserved. Global XP Share belongs to the separate server packages and is never installed on clients.

There are no manual Nexus downloads or original archive imports. OptiScaler, EML, Shroudtopia and the maintained minimap download automatically from pinned public releases. Visual C++ is downloaded only when needed. Verified files are cached and reused, allowing installation and profile switching offline once the required dependencies are available. Dependency downloads, especially the graphics libraries, are larger than the manager ZIP. Game-data patches are generated against the recipient's matching game installation.

Use **Check for updates** on the home screen, in Settings or in the tray menu. Automatic checks run at startup and every 30 minutes; checks and downloads wait while Enshrouded is running, and overdue checks resume after it closes. Disable automatic updates in Settings if preferred. Installation also requires the manager to be idle. The tray icon is blue for Normal and gold for Cheeze.

Previous Regular 4.x editions receive the small 4.2.1 compatibility update first, then the new manager through the bundled-release feeds. Users of Normal 3.9 or Cheeze 1.0.2 should close the old launcher through its tray menu and download this manager once. Regular stores its stable entry point and settings under `%LOCALAPPDATA%\EnshroudedClientMods`; Admin uses `%LOCALAPPDATA%\EnshroudedAdminMods`. Each Setup installation provides its own Start menu shortcut. An automatic update keeps its edition.

Signed metadata and SHA-256 checksums verify every app update. The `bundled-channels/stable`, `normal` and `cheeze` feeds identify the Regular package; `admin` identifies the separate Admin package. All four are promoted together after both packages pass build and setup checks. The legacy `channels` feeds retain 4.2.1 so launchers with the old size limit can migrate safely. Previous app versions and recovery backups are retained.
